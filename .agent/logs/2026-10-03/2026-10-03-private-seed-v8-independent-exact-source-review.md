## Independent new-page method

Applied the PDF skill's visual review workflow. The exact new source text and
full authenticated original-page PNG were placed together in local private
panels, and all eight panels were inspected. Original lecture file bytes were
matched to archive SHA values and page counts using local PDFs and `pypdf`.
No re-export, download or dependency installation was needed. The read-only
bundled runtime supplied Pillow for the local panels.

Each source cue was checked against its canonical page offsets and cue hash;
page text and source context were checked against their hashes/offsets. The
issued PNG, physical page, archive binding and existing label identity were
checked independently. This review uses the unchanged rubric:
`original_page_direct_or_concrete_connected_learning_step_and_cue_locates_v1`.
A page must explain the requested relation or a concrete connected learning
step; shared topic or generic prerequisite alone is insufficient. Page and
locating-cue usefulness are separate labels.

For both D04 and N12, **S01/S02/S03** explain the requested relationship and
their exact displayed cues locate it. They receive page/cue **Yes**, category
`direct`. **S04** describes a related property without the requested missing-
information relationship; it receives page/cue **No**, category `topic_only`.
No new slot is labelled Unsure. These are source decisions made before outcomes,
not an inference that any runtime-selected citation is useful.
