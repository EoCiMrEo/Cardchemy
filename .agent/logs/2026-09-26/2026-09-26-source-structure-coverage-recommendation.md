# Source structure coverage recommendation

Date: 2026-09-26. Status when written: proposal; subsequent owner approval is
recorded below. This record alone is not runtime or release evidence.

## Starting context and scope

The owner-approved Lane 6 path remains source-only. Ask is disabled. The current
v3 selector qualifies a heading with a bullet for property/limitation and
application/example. The remaining relation families require their predicate
inside an entity-bound source unit. This investigation read only the owner's
local published Knowledge and corresponding original lecture PDFs. It made no
provider request, reindex, database write or runtime configuration change.

## Findings

- An owner-authorized, read-only current-source snapshot contained 104 indexed
  chunks on 104 pages. Earlier owner review and seed probes exposed 31 distinct
  pages; these cannot become a new page-disjoint holdout.
- After those exclusions, the present fixed authored discovery filters found
  complete strict candidates on two definition pages and one property page.
  A weaker diagnostic found heading-owned topic/evidence text on two other
  definition pages and two mechanism pages. It did not establish semantic
  sufficiency or runtime selection. The filter pool covers a narrow set of
  lecture topics; its low yield does not imply the corpus lacks facts.
- Private visual inspection of unexposed original PDF pages found additional
  title-and-bullet presentations of operations, reasons, process steps,
  limitations and applications. The reviewed old packet had already shown
  that exact source identity can coexist with an insufficient excerpt.
- A concrete local synthetic selector check showed that a negative bullet
  under its own limitation title was missed; a narrow v3 correction now
  accepts an explicit negative/property opening while rejecting a different
  named subject. Public test passed. This does not prove private usefulness.

## Recommended next scope for owner decision

Extend **local source-unit qualification**, under a new immutable policy
identity, to a title-owned bullet/continuation for the remaining relation
families where the canonical indexed chunk already contains both. Require an
explicit relation predicate in the bullet, the requested entity in its owning
title or the same bullet, every requested condition in the displayed unit,
and no second subject borrowing the title. Keep each slice contiguous and
verbatim, no more than 480 characters, with no cross-chunk synthesis, no answer
draft, and no model-based verifier. Keep the existing 30-chunk/12-page/8,192-
token inspection, one-current-question embedding, zero answer/verifier calls,
and all owner-reviewed 12-positive/16-insufficient, retrieval, access and
release gates. Do not reindex unless a measured canonical-context loss requires
a separately approved staged procedure.

Independently, allow a bounded owner-private authored discovery input for
questions tied to unexposed pages, since fixed public templates do not cover
the lecture topics. This is a review-packet construction method: regex/literal
matches remain **unreviewed candidates**, and the owner must label exact
excerpt, PDF page and source fidelity before any gold roster is frozen. This
does not change runtime selection or quality thresholds.

## Limits and cleanup

The per-relation counts are diagnostics of authored filters, not corpus-wide
absence or recall. The current local Compose image still predates v3; no live
Ask result is claimed. Temporary PDF page renders used only for this visual
inspection must be removed after review. Ask remains off until displayed-window,
page-open, access and release gates pass.

## Owner decision and implementation boundary

On 2026-09-26, the owner approved adding this source-structure extension and
private authored review input to Lane 6/ADR-022 and implementing them. The
approved target versions are `hybrid_source_sufficiency_v4` and
`source_relation_units_v4`. Approval does not label any candidate page,
establish displayed-window quality, authorize a paid provider request or
activate Ask. The 12-positive/16-insufficient independent review and existing
access/release gates remain open.
