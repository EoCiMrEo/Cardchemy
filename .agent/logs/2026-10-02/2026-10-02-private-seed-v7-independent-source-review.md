# Independent current seed/source-control reading review

## Scope

Review the exact fourteen-case artifact from the
[provider-free retained preparation](2026-10-02-private-seed-v7-readonly-preparation.md)
before source-judge outcomes. The operator authorized independent evaluation;
the parent delegated only private Temp review outputs and this aggregate log.
No provider call, database access, key read, root `.env` inspection, runtime
change or app-source edit occurred in this review.

Applied the PDF skill's visual-review workflow. Inspected each exact current
cue together with its authenticated full original-page PNG, preserving headings,
tables, figures and formulas. The input was the already prepared local render;
no PDF re-export, network download or additional content transfer was needed.

## Method and preservation

- Bind the original preparation bytes by SHA-256 before building a new private,
  blinded review packet. Do not read model outcomes or prior source-selection
  scores when deciding labels.
- Check each exact cue against its canonical offsets and cue hash, its complete
  page text against the page hash, the physical page against its retained PDF
  binding, and the reviewed PNG bytes against the issued source request.
- Judge page usefulness using the current educational rubric: the requested
  relationship or a concrete learning step explicitly connected to it is useful;
  a shared topic, generic prerequisite or repetition alone is insufficient.
  Judge separately whether the exact cue locates that useful material.
- Review current-question clarity using only the supplied current question and
  strictly preceding user question. An unknown answer or missing evidence does
  not make a clear learning task ambiguous.
- Keep deliberately restricted wrong-source slates distinct from corpus-wide
  absence. Their page and cue labels are independent decisions, not defaults
  inferred from the control role. Historical deleted excerpt identities and
  owner labels were not reused as labels for these fresh cues.
- Preserve all fourteen cases, including two local zero-candidate observations.
  Original source/preparation files and labels are unchanged; the new review is
  an exclusive private Temp output. No private question, lecture text, source
  UUID, vector, PNG or credential is included here.

The backend virtual environment lacked Pillow. The first panel command stopped
at that import before opening private inputs or creating output. The read-only
workspace dependency locator supplied the bundled runtime with Pillow; no
dependency installation or runtime configuration change was needed.
