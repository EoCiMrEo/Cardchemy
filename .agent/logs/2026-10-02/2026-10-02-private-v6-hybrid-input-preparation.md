## Changes and boundaries

Added [the separate preparer](../../../backend/scripts/prepare_private_navigation_v6.py)
and [synthetic tests](../../../backend/tests/test_private_navigation_v6_preparation.py).
It requires exact external source/gold/vector hashes, the complete twelve-case
current-question roster and compatible QA embedding space. Its default CLI is
inert. Explicit preparation rejects AI credentials and enabled Ask/judge, does
not load the operator root settings file, and requires finite cgroup limits
of at most four CPU/two GiB.

The component uses production history resolution locally, hybrid retrieval,
bounded candidate pooling and visual source preparation in one repeatable-read,
read-only transaction. Current Subject ownership/enrollment, publication,
review/readiness, revisions, embedding space, canonical page hashes and exact
original-PDF blocks remain checked in SQL. All cases are retained, including
unclear follow-ups. It always rolls back and writes only an exclusive bounded
owner-private OS Temp artifact; no provider or database commit is made.

The internal deadline is cooperative. The execution caller must additionally
enforce a **hard 300-second process-tree limit**. Encoding/fsync deadline
checks prevent late success and remove an owned late output. Source authority
must be checked again before any later external transfer. Vector provenance
also requires the separate approved provider receipts and ledger; a file hash
alone is not provider-execution evidence.
