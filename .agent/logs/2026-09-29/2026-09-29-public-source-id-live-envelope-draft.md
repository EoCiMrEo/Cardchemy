## Proposed one-shot scope after the public packet is reviewed

- Endpoint: `https://generativelanguage.googleapis.com/v1beta/models/gemini-3.8-flash:generateContent`; model `gemini-3.8-flash`, standard synchronous API. [Official model](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash), [structured-output API](https://ai.google.dev/gemini-api/docs/structured-output).
- Input per call: only the **current question** and four independently reviewed, exact, public CC BY 4.0 candidate page snippets/cues with issued opaque IDs. The previous question and any local derived antecedent stay on the host. No private Cardchemy lecture, PDF bytes, user identity, account data, chat history, credentials or answer draft in content. No Google Search/tool use.
- Output: JSON object with only an ordered `selected_ids` array of zero to three issued IDs. Use low thinking and the model's supported default sampling parameters (do not send `temperature`, `top_p` or `top_k`); combined thinking/output cap 1,024 tokens. Locally reject malformed, duplicate, foreign or extra fields and any non-STOP finish. Empty valid output is not a transport failure. Google's [current Gemini 3.8 guidance](https://ai.google.dev/gemini-api/docs/latest-model) recommends omitting those sampling parameters; this correction precedes any pilot request.
- Requests: one physical judgment call per callable group, no SDK/application retries, at most 48 calibration calls. If and only if its pre-registered gate passes, at most 48 untouched public heldout calls. Maximum 96 calls total; do not silently replay an uncertain call. Single concurrency, at least six seconds between starts, 30 seconds per call and 90 minutes total. No embedding, answer generation, Knowledge indexing or database mutation in this pilot.
- Token ceiling: at most 8,192 input and 1,024 combined output tokens per call; at most 786,432 input and 98,304 output tokens across 96 calls. The exact complete REST JSON body is additionally capped at 8,192 UTF-8 bytes before transmission, but actual provider usage must be recorded separately. A keyless pass over 85 callable groups measured at most **7,813 REST bytes** after rendering the same exact page/cue content as compact tagged text; double-encoding the abstract JSON wire would have exceeded the cap on four groups. The tighter renderer was chosen before any score or call and preserves every exact source span.
- Conservative price guard: USD 1.50 per million input tokens and USD 7.50 per million output tokens, using the higher prices Google lists from January 2027 rather than its lower September 2026 introductory prices. Maximum estimate USD **1.916928**, rounded admission cap **USD 2.00**. Actual charges may differ; usage/receipts can be absent on failed or uncertain execution. [Official Gemini pricing](https://ai.google.dev/gemini-api/docs/pricing).
- Write a one-shot attempt marker before any network call; store only public ID response and content-free finish/usage/cost receipts in OS Temp. Stop on a failed, partial, uncertain, malformed or over-budget response. Do not rerun a consumed split or open heldout after calibration failure. No private source egress or Ask activation follows automatically, even if public results pass.
