# Historical Documentation

Files here are historical reference, not current instructions or descriptions
of shipped capabilities. Start with [canonical orientation](../00-START-HERE.md)
and the [current guide index](../README.md).

Use the [public roadmap](../../ROADMAP.md) to distinguish implemented work from
proposals; historical toolkit affiliation, broker, offline/PWA and quiz/rewards
ideas are not current product commitments.

| Material | Classification |

| [Subject-Scoped RAG Implementation Plan](<Cardchemy-Subject-Scoped RAG Implementation Plan.md>) | Completed Preparation A/B and Phases 12–21 checklist; historical task and gate detail, not current instructions |

Archive a document only after checking its current consumers and replacing
active navigation with a maintained source. Add a clear historical banner and
an index entry; preserve useful rationale as an ADR when appropriate. Keep an
in-progress tracker outside the archive; archive it only after all items close
and current status/proposals move to maintained sources.

Completed dated [agent logs](../../.agent/logs/README.md) remain in their log
folders as historical evidence. Do not move them merely because they are old,
or treat earlier implementation paths/status as current truth. Maintenance
rules live in [AGENTS.md](../../AGENTS.md).
